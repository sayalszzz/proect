# Исправления проекта proect

## Рефакторинг

- Поля моделей закрыты, а сами модели сделаны неизменяемыми.
- Контактные данные вынесены в `Customer`, пищевая ценность — в `NutritionInfo`.
- Статусы представлены перечислением `OrderStatus`.
- Единый `mapDish()` используется для всех результатов JDBC.
- Длинная загрузка заказов разделена на `orderSelect()`, `mapOrders()` и `mapDish()`.
- Входные данные проверяются в конструкторах и перед SQL-операциями.
- Исключения БД преобразуются в понятные прикладные исключения и показываются интерфейсом.
- Стоимость заказа вычисляется внутри `Order`; для процентов используется константа `PERCENT_BASE`.

## Оптимизация

- `PreparedStatement` используется для пользовательских значений.
- Заказ и позиции сохраняются одной транзакцией с `rollback` при ошибке.
- Заказы и блюда загружаются страницами по 10 записей.
- Позиции заказов загружаются одним `JOIN`, без N+1.
- Созданы индексы для категории, названия блюда, `order_id`, статуса и времени заказа.
- Поиск и фильтр выполняются в SQL; динамическая часть строится через `StringBuilder`.
- Страницы меню кэшируются и сбрасываются после изменения меню.
- Нормализованные строки вычисляются до циклов и привязки параметров.
- JDBC-ресурсы закрываются через `try-with-resources`.
- Все запросы интерфейса выполняются в фоновом JavaFX `Task`.
