# Ресторан proect

Исправленная версия приложения группы 6. Программа управляет меню и заказами ресторана через JavaFX и хранит данные в SQLite.

## Возможности

- добавление блюд;
- поиск и фильтр категорий;
- выбор нескольких блюд;
- формирование и оформление заказа;
- история заказов и смена статуса;
- расчёт выручки;
- пагинация меню и истории;
- сохранение данных между запусками.

## Запуск

1. Открыть проект в IntelliJ IDEA.
2. Обновить Maven-зависимости.
3. Запустить `src/Main.java`.

Для JDK 24 можно добавить VM option `--enable-native-access=ALL-UNNAMED`, чтобы скрыть предупреждение SQLite JDBC.
